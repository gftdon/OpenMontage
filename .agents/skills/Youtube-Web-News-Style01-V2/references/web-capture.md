# Web capture reference — real page, exact sentences, exact coordinates

Goal: PNG captures of the page the presenter talks about **plus** the bounding
box of every sentence that will be highlighted, so the composition can pan to
and mark the real text at the right word. `scripts/capture_page.mjs` does all
of it from one JSON config in a single page load.

## Why one run, anchored to headings

Page height varies between loads by tens of px (fonts, consent bars, lazy
embeds). Coordinates measured in one load do not line up with a PNG captured in
another. So: every section's `y` is derived from a heading/paragraph **anchor**
(`anchor − 40`), phrase rects are converted to **section-relative** css px in
that same run, and the PNGs are written in that same run. Re-run the whole
script after any config change; never hand-merge partial outputs.

## Capture settings

- Viewport 1100 css px, DPR 2 → PNGs are 2200 px wide; the composition maps
  1100 css → 1210 stage px (`S0 = 1.1`), so text stays crisp up to zoom ≈ 1.6.
- Sections should be ≥ 800 css px tall whenever the beat must scroll to a
  sentence; use short captures (240–460) only for single paragraphs, which the
  composition centres.
- `hideSelectors`: cookie/consent containers (`[class*="Consent"]`), chat
  widgets, sticky promo bars.
- The script scrolls the whole page once before capturing: scroll-triggered
  charts and reveal animations otherwise capture blank.

## Config blocks

| Block | What it yields | Notes |
|---|---|---|
| `sections[]` | `sec_<name>.png` + `WEB_CLIPS[name]` | `y` literal or `anchor` text (`startsWith`, quotes/dashes normalised, default `anchorSelector` = `h1,h2,p,strong` — widening it to `li`/`a` matches table-of-contents links and anchors the wrong place) |
| `sections[].phrases` | `WEB_RECTS[key]` | value = `"text"` or `["text", nth]`; nth counts matches over the whole page |
| `tables[]` | `<name>_box`, `<name>_rowN` (with `text`), `<name>_colN` (x/w only) | row rects let you highlight a whole row; combine with a col for one cell |
| `tabs[]` | `<name>_N.png` + `WEB_CLIPS["<name>_N"]` | clicks each label (`force: true`), waits 2 s, screenshots the nearest ancestor ≥ `minHeight` |
| `carousel` | `<name>_NN.png` + `WEB_CLIPS[name]` + item phrases | clicks the text pagination button `items[].index` times; arrows are often hidden at this viewport |
| `downloadVideosTo` | `videos.json` + `page_video_N.*` | `<video>.currentSrc` (webm/mp4) — official b-roll, free to use editorially |

## Phrase matching rules

- Text is compared after collapsing whitespace and normalising `‘’“”` → `'"`,
  and every dash variant (`– — ‑ ‐ −`, including **U+2011 non-breaking hyphen**
  used in "Terminal‑Bench") → `-`. Write phrases with plain ASCII punctuation.
- Copy 6–12 words verbatim from the page; shorter phrases hit the wrong
  occurrence (use `nth`), longer ones cross element boundaries and fail.
- A `MISS` line in the log = the phrase isn't on the page as written. Check the
  full-page screenshot, fix wording, re-run.
- Footer text is excluded from matching.
- Anchors and phrases both pass through the same normaliser, so `We're` matches the page's `We’re`. A wrong-but-present anchor (`ANCHOR MISS` absent, section `y` far from where you expect) means an earlier element starts with the same words — narrow `anchorSelector` to `h2` or lengthen the anchor text.

## After the run

```bash
cp projects/<slug>/assets/web/*.png remotion-composer/public/<mediaDir>/web/   # real copies, never symlinks
```
`tsOut` is the TS module the composition imports (`WEB_CLIPS`, `WEB_RECTS`).
Tab captures are stored in `WEB_CLIPS` as `<name>_N` (0-indexed: `chart_0` is
the first tab) and the composition looks them up by file name, so `cssH` is
only a manual override. (EP.1's module was generated by an earlier script and
lacks them, which is why its chart beats carry `cssH`.)

## Recon before writing the config

```bash
node scripts/explore_page.mjs "<URL>"                       # headings + y, tab labels, buttons, <video> srcs
npx playwright screenshot --full-page --viewport-size=1100,900 --wait-for-timeout=6000 "<URL>" full.png
```
Tile `full.png` into ~2000 px strips (PIL) and view them; write the
section→script-line map from that.

## Known page-specific facts (anthropic.com launch pages, 2026)

- Testimonial carousel: `button[class*="pagination-button"]` with text `Next`,
  "N of 22" counter in the DOM; the card is taller than its container (capture
  340 css px, not the container's 308).
- Benchmark tabs: `button[class*="ViewSwitcher"]`; the chart container is the
  first ancestor ≥ 500 px tall.
- Table header row text is `" Fable 5.1 Fable 5 Opus 5 GPT-5.6 Sol"`; cells use
  U+2011 hyphens; some `tr` rows have zero size (mobile duplicates) — ignore
  rows with `w == 0`.
- Hero has Noon/Night/Morning looks (buttons); default Noon (blue sky + moon)
  captures best.
